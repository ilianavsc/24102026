## 🚑 Mi Bitácora de Errores (Lo que aprendí a golpes)
Documentar los errores es lo más valioso. Hoy me topé con varios:
*   **Error:** `'git' no se reconoce...`
    *   *Solución:* No lo tenía instalado. Lo descargué y aseguré de agregar Git al PATH de Windows.
*   **Error:** `touch` no se reconoce en PowerShell.
    *   *Solución:* Aprendí que en Windows se usa `ni` (New-Item) o simplemente creo los archivos desde el explorador de VS Code.
*   **Error:** `Author identity unknown`.
    *   *Solución:* Git necesitaba saber quién soy. Lo solucioné con `git config --global user.name` y `user.email`.
*   **Error:** `CONFLICT (content): Merge conflict in style.css`.
    *   *Solución:* Resolví el conflicto visualmente en VS Code usando los botones de "Aceptar cambio" y finalizando con un commit.
*   **Error:** `error: invalid path 'S06-jetpack-room/CL04-... /'` al clonar el curso de Android.
    *   *Solución:* Windows no permite espacios al final de los nombres de carpetas. Lo arreglé con `git config --global core.protectNTFS false` y `git restore`.
