### 🧠 SUPER RESUMEN: Unidad 1

**1. La diferencia clave:**
- **Git:** Programa local (tu "cámara de fotos").
- **GitHub:** Plataforma en la nube (tu "álbum de fotos").

**2. El Flujo de Trabajo Básico (día a día):**
1. `git add .` (Preparas los archivos).
2. `git commit -m "Mensaje"` (Guardas la foto).
3. `git push` (Subes a GitHub).

**3. Los 3 Comandos de Supervivencia:**
- `git clone [url]` (Descargar proyecto de GitHub).
- `git checkout -- [archivo]` (Deshacer cambios en un archivo).
- `git pull` (Descargar cambios de GitHub antes de subir).

**4. Trabajo en equipo (Regla de oro):**
- Nunca trabajar directo en `main`.
- Crear una **rama** individual y pedir un **Pull Request**.
